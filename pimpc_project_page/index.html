ADMM-based solver for real-time constrained NMPC

πMPC: A Parallel-in-horizon and Construction-free NMPC Solver

Abstract

The alternating direction method of multipliers (ADMM) has gained increasing popularity in embedded model predictive control (MPC) due to its code simplicity and pain-free parameter selection. However, existing ADMM solvers either target general quadratic programming (QP) problems or exploit sparse MPC formulations via Riccati recursions, which are inherently sequential and therefore difficult to parallelize for long prediction horizons. This technical note proposes a novel parallel-in-horizon and construction-free nonlinear MPC algorithm, termed πMPC, which combines a new variable-splitting scheme with a velocity-based system representation in the ADMM framework, enabling horizon-wise parallel execution while operating directly on system matrices without explicit MPC-to-QP construction. Numerical experiments and accompanying code are provided to validate the effectiveness of the proposed method.

Problem Formulation

πMPC solves constrained finite-horizon MPC subproblems directly from the system matrices. A common bound-constrained form is:

\[ \begin{aligned} \min_{x,u} \quad & \sum_{k=0}^{N-1} \left( \lVert Cx_k-r_y \rVert_{W_y}^2 + \lVert u_k-r_u \rVert_{W_u}^2 + \lVert \Delta u_k \rVert_{W_{\Delta u}}^2 \right) + \lVert Cx_N-r_y \rVert_{W_f}^2 \\ \text{s.t.} \quad & x_{k+1} = A x_k + B u_k + e, && k=0,\ldots,N-1, \\ & x_{\min} \le x_k \le x_{\max}, && k=0,\ldots,N, \\ & u_{\min} \le u_k \le u_{\max}, && k=0,\ldots,N-1, \\ & \Delta u_{\min} \le \Delta u_k \le \Delta u_{\max}, && k=0,\ldots,N-1. \end{aligned} \]

Here \(A\), \(B\), and \(e\) are the discrete-time state matrix, input matrix, and affine term. The matrices \(W_y\), \(W_u\), \(W_{\Delta u}\), and \(W_f\) weight output tracking, input usage, input increments, and terminal tracking. More general constrained updates can be handled through projection-friendly ADMM sets, while the package API exposes the common state, input, and input-rate bounds.

Methodology

New variables make the horizon parallel.

Start from the linear-time-varying MPC subproblem produced by online linearization or a real-time iteration nonlinear model predictive control (RTI-NMPC) step. The augmented dynamics matrices \(\bar A_{t,k}\) and \(\bar B_{t,k}\) are re-linearised online at each time step \(t\) and may vary across stages \(k=0,\ldots,N-1\). The stage cost penalizes output tracking error and input increments, while the terminal cost is applied at the final stage. Traditional ADMM approaches require assembling a huge KKT matrix from the stage-varying \(\bar A_{t,k}\) and \(\bar B_{t,k}\) and refactorising it at every outer MPC step, which is a cubic in the prediction horizon operation that scales with horizon length and must be repeated whenever the linearisation changes. This is the work πMPC is designed to eliminate.

Generalized LTV MPC subproblem
\[ \begin{aligned} \min_{U,X}\quad &\sum_{k=0}^{N-1} \frac{1}{2}\lVert Cx_{k+1}-r_y\rVert_{W_y}^{2} +\frac{1}{2}\lVert u_k-r_u\rVert_{W_u}^{2}\\ \text{s.t.}\quad &x_{k+1}=A_{t,k}x_k+B_{t,k}u_k+e_{t,k},\\ &u_k\in\mathcal U,\quad x_{k+1}\in\mathcal X,\quad x_0=x(t). \end{aligned} \]

With \(y=\operatorname{col}(u_0,x_1,\ldots,u_{N-1},x_N)\), conventional implementations assemble the sparse QP \(\min_y \frac12 y^\top H_t y+h_t^\top y\;\text{s.t.}\;E_ty\in\mathcal Y_t\). For time-varying NMPC, \(E_t\) and \(\mathcal Y_t\) change online.

01

Where previous ADMM remains sequential

General QP-ADMM couples the complete vector through \((H_t+\rho E_t^\top E_t)^{-1}\). Structure-exploited ADMM avoids that dense inverse with a Riccati recursion, but the recursion still passes information stage by stage through the horizon.

02

πMPC copies the effect of the input

The decisive change is not cosmetic. Instead of copying the input as \(v_k=u_k\), πMPC introduces

\(\mathbf{v_k=\bar B_{t,k}\Delta u_k}\)

and places the constrained future-state copy \(\mathbf{z_{k+1}}\), rather than \(x_{k+1}\), inside the split dynamics. This absorbs \(\bar B_{t,k}\) locally and breaks the long Riccati chain.

πMPC's three new consensus relations
\(\bar x_{k+1}-z_{k+1}=0\)
\(\mathbf{\bar B_{t,k}\Delta u_k-v_k=0}\)
\(z_{k+1}-\bar A_{t,k}\bar x_k-v_k-\bar e_{t,k}=0\)
Parallel-in-horizon

Every stage reads one frozen iterate. Every stage updates together.

At ADMM iteration \(i\), every worker reads the same frozen previous iterate; with Nesterov acceleration, this becomes the extrapolated or momentum iterate. Stage \(k\) may read frozen values from the adjacent iterate columns \(k+1\) and \(k+2\), including \(\hat z_{k+1}\) and \(\hat z_{k+2}\), but it never waits for another stage to finish iteration \(i+1\). This frozen-iterate boundary turns the horizon loop into a CPU batch or GPU kernel.

\(k=0\)\(k=1\)\(k=2\)\(\cdots\)\(k=N-1\) simultaneous update
1

Local primal update

Each stage applies cached \(J_k\) and the appropriate interior or terminal operator to compute \(\Delta u_k^{i+1}\) and \(\bar x_{k+1}^{i+1}\) from the frozen iterate.

2

Project and copy

Projection enforces \(\bar x_{k+1}\in\bar{\mathcal X}\), the joint state-input constraint set, while \(z_{k+1}\) and \(v_k\) reconcile local dynamics with constrained copies.

3

Dual consensus

\(\theta_k\), \(\beta_k\), and \(\lambda_k\) accumulate violations of the three split equalities. All \(k\) update in parallel.

After all stage kernels finish

Three lightweight horizon-wide operations

1. Squared-norm reduction. Sum five squared-norm terms across all N stages in parallel — O(N), no sequential dependency.

2. Restart check. If ci+1 ≤ ηci, update momentum α; otherwise reset αi+1 = 1 — a single scalar comparison.

3. Nesterov extrapolation. Extrapolate all N stage columns simultaneously to form ŷi — O(N), fully parallel.

\[ c^{i+1}=\rho\sum_{k=0}^{N-1}\!\left( \lVert\theta_k-\hat\theta_k\rVert^2+ \lVert\beta_k-\hat\beta_k\rVert^2+ \lVert\lambda_k-\hat\lambda_k\rVert^2+ \lVert z_{k+1}-\hat z_{k+1}\rVert^2+ \lVert v_k-\hat v_k\rVert^2\right). \]
Construction-free

Cache small stage operators, not one giant online QP.

πMPC works directly with \(\{\bar A_{t,k},\bar B_{t,k},\bar e_{t,k}\}\). Each stage caches the compact operator \(J_k=(W_{\Delta u}+\rho\bar B_{t,k}^{\top}\bar B_{t,k})^{-1}\bar B_{t,k}^{\top}\), together with \(H_A\) for interior stages and a distinct \(H_{AN}\) for the terminal stage. The terminal operator differs because there is no forward dynamics step beyond stage \(N\). These small operators are then reused in the closed-form ADMM updates without constructing one horizon-wide QP.

Adaptive Nesterov acceleration

If \(c^{i+1}\leq\eta c^i\), πMPC extrapolates every stage variable in parallel using \(\alpha_{i+1}=\frac12+\frac12\sqrt{1+4\alpha_i^2}\). Otherwise it restarts with \(\alpha_{i+1}=1\), protecting convergence when momentum stops helping.

Warm start across control steps

After applying the first control action, the solved state, input, copy, and dual trajectories are shifted by one stage. The newly exposed tail is initialized explicitly, typically with zeros or by repeating the final available stage, so the next MPC solve begins near its new consensus point without leaving an ill-defined tail.
